# Maroqand Quiz — sayt

Samarqanddagi intellektual va emotsional quiz o'yinlari sayti: o'yin haqida ma'lumot, emotsiyalar galereyasi va keyingi o'yinga ro'yxatdan o'tish.

- `index.html` — sahifa
- `assets/style.css` — dizayn
- `assets/app.js` — sozlamalar (o'yin vaqti, manzil, narx, galereya) va interaktiv qismlar
- `assets/media/` — rasm va video
- `api/register.js` — arizani Telegram guruhga yuboradi (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`)
